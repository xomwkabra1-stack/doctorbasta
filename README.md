# دکتۆر بەستە 🧠 | Dr. Basta - Kurdish Psychological AI Assistant

بەرنامەی مۆبایلی ئەندرۆید بۆ ڕاوێژکاری دەروونی بە کوردیی سۆرانی لەگەڵ زیرەکی دەستکردی Gemini.

---

## ناسنامەی دکتۆر بەستە (About Dr. Basta)

**«دکتۆر بەستە | دکتۆری دەرونی 🧠»** یاریدەدەر و ڕاوێژکارێکی دەروونییە کە تایبەت بە زمانی شیرینی کوردیی سۆرانی ئامادە کراوە بۆ ئەوەی بە گەرمی، دڵسۆزی، ژیری و شێوازی دۆستانە لەگەڵ خەڵک بدوێت. بەرنامەکە هاوکاری دەروونی پێشکەش دەکات بۆ تێگەیشتن لە کێشەکانی:
- زۆر بیرکردنەوە (Overthinking) و بێخەوی
- دڵەڕاوکێ (Anxiety)، ترس و پەشۆکاوی
- بێتاقەتی، ماندووبوونی دەروونی و خەمۆکی
- کێشە و ئاڵۆزییەکانی پەیوەندییە سۆزداری و کۆمەڵایەتییەکان
- توڕەیی و کۆنتڕۆڵنەکردنی هەڵچوونەکان
- کەمبوونی متمانە بەخۆبوون و شەرمی کۆمەڵایەتی

---

## تایبەتمەندییە سەرەکییەکان (Features)

1. **کوالێتی بەرزی زمانی کوردی (Natural Sorani Kurdish)**:
   - بەکارهێنانی ڕێزمانی دروستی کوردی و ڕستەسازیی سروشتی (نەک وەرگێڕانی وشەبەوشەی ئینگلیزی).
   - تێگەیشتن لە پەند، قسەی عەشایەری و زاراوە ڕۆژانەییەکان.
   - پشتگیریی تەواوی ئاڕاستەی ڕاست بۆ چەپ (RTL Layout) بە فۆنت و قەبارەی ڕوون و خوێنراوە.

2. **وەڵامی تێروتەسەل و دەروونناسیی کرداری (Psychological Quality)**:
   - وەڵامدانەوەی ڕاستەوخۆ و دروست بۆ کێشەکە.
   - شیکردنەوەی دەروونی و هۆکاری ڕوودانی لە مێشکدا.
   - ٣ بۆ ٥ هەنگاوی کرداری کە بەکارهێنەر دەتوانێت ڕاستەوخۆ جێبەجێیان بکات.
   - نموونەی زیندوو لە ژیانی ڕاستەقینە و پرسیاری بەدواداچوونی گەرم.
   - گونجاندنی درێژیی وەڵام بەپێی ویستی بەکارهێنەر (٢ بۆ ٦ کورتە پەرەگراف، نزیکەی ١٥٠ تا ٤٠٠ وشەی کوردی).

3. **نوکتە و خۆشیی کوردی لەگەڵ هێڵی سووری سەلامەتی (Humor & Safety)**:
   - کۆمیدیای سووک و دۆستانە لە کاتی گونجاودا بۆ کەمکردنەوەی سترێس.
   - هێڵی سووری پەڕگیر: بە هیچ شێوەیەک گاڵتە بە بابەتی خۆکوژی، ئازاردانی خۆ، مەرگ، یان نەخۆشیی سەخت ناکرێت؛ لە کاتی لەناکاودا یەکسەر دەگۆڕێت بۆ دۆخی فریاگوزاری و ڕێنمایی نەخۆشخانە و کەسانی نزیک.

4. **پاشەکەوتکردنی پارێزراوی کلیلی API لە ڕێگەی Android Keystore**:
   - لاپەڕەی تایبەتی ڕێکخستنەکان (Settings).
   - کلیلی Gemini API لە ڕێگەی **Android Keystore** بە کۆدکردنی ڕەقامێریی **AES-256 GCM** لەسەر مۆبایلەکە بە پارێزراوی دەمێنێتەوە.
   - پیشاندانی بە شێوەی شاردراوە (`AIza••••••••9xQ`)؛ هیچ کات کلیلەکە لە کۆد یان لاپەڕە گشتییەکان دەرناکەوێت.
   - دوگمەی تاقیکردنەوەی کلیلی API لەگەڵ پەیامی سەرکەوتن یان هەڵەی ڕوونکراوە بە کوردی.

5. **هەڵبژاردنی مۆدێلەکانی Gemini (Model Selection)**:
   - پشتیوانی لە مۆدێلەکانی: `gemini-2.5-flash`، `gemini-2.5-pro`، `gemini-1.5-flash`، `gemini-2.0-flash`.

6. **ڕووکاری پێشکەوتوو و هاوچەرخ (Modern App UI)**:
   - دیزاینی Material Design 3.
   - دوگمەی سەرلەنوێ وەڵامدانەوە (**Regenerate Response 🔄**) بۆ هەموو وەڵامەکانی دکتۆر بەستە.
   - دوگمەی کۆپیکردنی وەڵام بۆ ناو بیرگە (**Copy 📋**).
   - دوگمەی گفتوگۆی نوێ (**➕ New Chat**) بە پەنجەرەی دڵنیابوونەوە.
   - پیشاندەری جوڵاوی بیرکردنەوە (Typing Indicator).
   - ڕاهێنانی هێورکەرەوەی هەناسەدانی ٤-٧-٨ (Guided Breathing Exercise).
   - داتابەیسی ناوخۆیی Room بۆ مانەوەی مێژووی چاتەکان بە پارێزراوی لەسەر ئامێرەکە.

## بونیادی تەکنیکی پڕۆژەکە (Architecture)

- **Language**: Kotlin 2.2
- **UI Framework**: Jetpack Compose (Material Design 3)
- **Architecture**: MVVM (Model - View - ViewModel) + Repository Pattern
- **Local Database**: Room Database 2.7 (SQLite)
- **Networking**: Retrofit 2 + OkHttp + Moshi (Kotlin Reflection & Codegen)
- **Security**: Hardware-backed Android Keystore + AES/GCM/NoPadding Cipher
- **Concurrency**: Kotlin Coroutines & StateFlow

## چۆنیەتی دروستکردن و دامەزراندن (Build & Installation)

### پێداویستییەکان:
- Android Studio Ladybug یان نوێتر
- JDK 17 (Java Development Kit)
- Android SDK 34 یان 35

### دروستکردنی فایلی APK:
دەتوانیت لە ڕێگەی تێرمیناڵەوە فایلی APK دروست بکەیت:

```bash
# لە لینوکس یان ماک
./gradlew assembleDebug

# لە ویندۆز
gradlew.bat assembleDebug
```

فایلی دروستکراو دەکەوێتە ئەم شوێنە:
`app/build/outputs/apk/debug/app-debug.apk`
